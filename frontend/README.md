# frontend

Panel administrativo y bandeja de conversación de `epm-wa-platform` (Next.js App Router + TypeScript + Tailwind + shadcn/ui).

Ver el [`README.md`](../README.md) de la raíz del repo para el arranque completo (Docker Compose) y [`CLAUDE.md`](../CLAUDE.md) para las convenciones del proyecto.

```bash
npm install
npm run dev
```
